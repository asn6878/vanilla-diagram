## Vanilla Infographics 0.0.1

The first public release of `vanilla-infographics`: an agent skill for clear, animated infographics in plain JavaScript.

- Codex and Claude Code support, with personal and project installation.
- A dependency-free Canvas player with five playback speeds, pause, reverse, and timeline scrubbing.
- Responsive layouts, light and dark themes, and reduced-motion support.
- A reusable scene template, drawing helpers, and a ten-color palette.
- Two working examples with recorded GIFs and editable JavaScript source.
- English and Korean READMEs, plus the wooden VI logo and banner.

### Install

Clone the repository, then choose your agent:

```bash
git clone https://github.com/asn6878/vanilla-infographics.git
cd vanilla-infographics
node scripts/install.mjs --agent codex
# Or: node scripts/install.mjs --agent claude
```

The attached `vanilla-diagram-skill-v0.0.1.zip` is a ready-to-install skill folder. Extract `vanilla-diagram/` into `~/.agents/skills/` for Codex or `~/.claude/skills/` for Claude Code. Its checksum is included in `SHA256SUMS.txt`.

### Try the examples

Run `npm run dev` and open `http://localhost:4310/examples/`. No dependency installation is needed to preview the examples. Playwright and FFmpeg are development tools for regenerating the recordings.
